STEP 1 [independent]

Design and write the builder module
`launchpad/project-intelligence/corpus/index_defs/normative_documents.py`
(module-level `SPEC`, `name: "normative-documents"`,
`output_path: "specifications/normative-documents.md"`,
`node_id: "specifications-normative-documents"`, `node_type: "governance"`).

Inclusion rule (deterministic, path + type + content, never prose judgement): a
canonical node qualifies iff (a) `ctx.rel_path(n)` starts with the literal
prefix `specifications/` (same base set #1302 walks), AND (b) the node's own
front-matter `type` is not `governance` (excludes meta/index documents living
in that path, e.g. `specifications/INDEX.md` itself -- a real specification's
own `type` varies by subject per `templates/specification.md` but is never
`governance`, which this corpus reserves for meta-documents), AND (c) the
node's raw file text (read from `node.path`, front matter and body both, since
a normative-language declaration may sit in either) matches, case-insensitively,
one of the literal forms `RFC 2119`, `RFC2119`, `RFC 8174`, `RFC8174`, `BCP 14`,
`BCP14` -- the identical keyword set `templates/specification.md`'s own
evidence ledger greped for. The module docstring states this three-part test
explicitly, states the zero-match fact at time of writing (`INDEX.md` is
excluded by rule (b) alone, and nothing else exists under the prefix), and adds
an "Interpreting normative" section to the generated body's `sections` return
value stating explicitly: #1302/`specifications-index.md` already covers every
node under `specifications/` regardless of type or content; this document
narrows that to the subset which is both specification-shaped (non-`governance`
typed) AND makes a checkable normative-language-convention claim in its own
text -- so a reader knows which of the two documents to consult for which
question, and this one is not a duplicate of that one.

`relationships`: `references -> corpus-agents`, `implements ->
corpus-template-generated-index`, `references -> corpus-template-specification`
(mirrors #1302; all three confirmed present on this base).

done when: the module file exists, exposes `SPEC`, and
`python3 launchpad/project-intelligence/corpus/indexes.py --list` shows
`normative-documents` without error.
